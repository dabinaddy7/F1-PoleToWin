# 🏎️ F1 Pole-to-Win & Grid Position Analysis

Formula 1(F1) 데이터를 활용하여 예선 성적(Pole Position, Grid)과 본선 우승 간의 연관성 및 시대별 변화 흐름을 다각도로 분석하는 프로젝트입니다.

---

## 📌 프로젝트 개요 및 주요 분석
* **시대별(Decade) Pole-to-Win 승률 분석**: 폴 포지션(1위 출발)을 차지한 드라이버가 실제 우승까지 이어진 비율을 시대별로 추적하여, F1 레이스 환경 및 기술 변화에 따른 우승 난이도를 파악합니다.
* **대역전극 TOP 5 도출**: 그리드 하위 순위(가장 낮은 출발 위치)에서 출발해 본선 우승을 거머쥔 역사적인 대역전극 기록을 추출합니다.
* **완주 여부(Status) 데이터 정제**: 정규표현식을 활용하여 완주 차수 및 미완주 상태를 체계적으로 분류하고 데이터 전처리를 진행합니다.
