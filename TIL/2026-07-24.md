# 🏎️ 2014년 이후 F1 팀별 피트스탑(Pitstop) 수행 성능 분석

## 📌 1. 분석 배경 및 목표
* **배경**: F1에서 피트스탑 속도는 경기의 승패를 가르는 핵심 요인입니다. 하지만 단순 평균을 내면 서킷별 구조 차이, 규정 변경, 경기 중 발생하는 사고/패널티 등으로 데이터가 심하게 왜곡됩니다.
* **목표**: 2014년 현대 F1 규정 도입 이후의 피트스탑 데이터를 정제하고, 스폰서/엔진 변경으로 파편화된 팀 계보를 통합하여 **실질적인 팀별 순수 피트스탑 수행 역량**을 비교 및 분석합니다.

---

## 💡 2. 데이터 전처리 및 핵심 로직 (Troubleshooting & Insights)

### ① 현대 F1 규정 기준 필터링 (`Year >= 2014`)
* **이유**: 2014년부터 피트레인 속도 제한 규정이 **80km/h로 일괄 통일**되어 기준선이 명확해졌습니다. 이전 연도의 데이터(100km/h 등)와 섞일 경우 발생하는 환경적 오차를 제거했습니다.

### ② 서킷 차이를 고려한 상대적 이상치 필터링 (핵심 로직)
* **문제점**: 
  * 피트레인 길이와 제한 구간은 서킷마다 완전히 다릅니다. (예: 모나코 ~20초 vs 실버스톤 ~25초 이상)
  * 절대적인 시간(예: 25초 이상 제거)을 기준으로 자르면 특정 서킷의 피트스탑이 통째로 삭제되는 오류가 발생합니다.
* **해결 로직**:
  1. `(연도, 서킷)` 그룹별 피트스탑 시간의 **중앙값(Median)**을 기준선(`race_medians`)으로 산출.
  2. 개별 스탑 시간에서 중앙값을 뺀 **지연 시간(`pit_delta`)**을 계산.
  3. `pit_delta <= 5.0초` 조건으로 **해당 경기 평균 대비 +5.0초를 초과 지연된 스탑만 이상치로 제거**.
* **왜 +5초인가? (의문점 해결)**:
  * Pure한 타이어 교체 오차는 1~3초 내외입니다.
  * 지연 시간이 +5초를 초과한다는 것은 **5초/10초 패널티 수행, 프론트 윙 교체, Wheel Nut 장비 고장, Unsafe Release 회피 대기** 등 피트크루의 순수 교체 역량 외적인 이벤트가 개입했음을 의미합니다.

### ③ 파편화된 팀 계보 통합 (Parent_Team Mapping)
* **문제점**: F1 팀은 스폰서 및 엔진 공급사 변경으로 인해 데이터상 이름이 수시로 바뀝니다. (예: Racing Point $\rightarrow$ Aston Martin, Toro Rosso $\rightarrow$ AlphaTauri $\rightarrow$ RB)
* **해결 로직**: 실질적인 개발/운용 주체인 **모체 공장(Base Factory)** 기준으로 팀을 그룹핑하는 `team_mapping_full` 딕셔너리를 작성하여 통합 집계했습니다.

## 🛠️ 3. 주요 사용 메서드 & 파이썬 기능

| 메서드 / 기능 | 역할 및 활용 목적 |
| :--- | :--- |
| **`pd.to_numeric(..., errors='coerce')`** | 문자열 형태의 `Time` 컬럼을 수치형(초)으로 변환. 변환 불가능한 값은 `NaN` 처리. |
| **`groupby(['Year', 'Grand Prix'])`** | 연도 및 서킷 단위로 데이터를 분할하여 서킷별 특성을 독립적으로 반영. |
| **`.transform('median')`** | 그룹별 중앙값을 원본 데이터프레임의 행 수와 동일한 크기로 늘려서 반환 (편차 계산용). |
| **`.map(dict).fillna(...)`** | 딕셔너리를 활용해 팀명을 매핑하고, 딕셔너리에 없는 팀은 원본 이름 그대로 유지. |
| **`.agg({'Time_sec': ['mean', 'count']})`** | 그룹별 평균 피트스탑 시간과 샘플 수(총 피트스탑 횟수)를 동시에 계산. |
| **`.sort_values(by=..., ascending=True)`** | 평균 피트스탑 시간이 짧은(빠른) 순서대로 정렬. |

## 🔍 4. 분석 결과 요약
1. **데이터 정밀도 향상**: 서킷별 중앙값 보정 및 +5초 지연 이상치 제거를 통해, 노이즈가 제거된 '순수 타이어 교체 능력' 데이터 세트를 성공적으로 구축했습니다.
2. **실제 팀 역량 평가**: 파편화되어 있던 과거 팀 기록들이 통합됨에 따라 메르세데스, 레드불 레이싱, 페라리 등 주요 팀들의 현대 F1 피트스탑 작업 효율성을 객관적으로 비교할 수 있게 되었습니다.
